# Funktionen von disslxt

Eine Seite pro Funktion: was sie tut, Bedienung, Regeln, Technik und Tests.
Bei Änderungen an einer Funktion die Seite mitpflegen.

## Chat

- [Nachrichten](nachrichten.md): Text in Kanälen und privaten Chats, in Echtzeit bei allen, die den Kanal offen haben.
- [Text formatieren und Links](formatierung.md): Einfaches Markdown und klickbare Links in Nachrichten.
- [Reaktionen](reaktionen.md): Emoji unter Nachrichten, sichtbar für alle im Kanal.
- [Antworten mit Zitat](antworten.md): Eine Nachricht bezieht sich sichtbar auf eine andere.
- [Erwähnungen](erwaehnungen.md): `@name` ruft jemanden gezielt und benachrichtigt ihn.
- [Emoji-Auswahl und Kürzel](emoji.md): Emoji einfügen per Auswahl oder `:kürzel:`.
- [Befehle](befehle.md): Kurzbefehle im Eingabefeld, sie senden normalen Text.
- [Ungelesen](ungelesen.md): Zeigt auf jedem Gerät, was neu ist.
- [Schreibt gerade](schreibt-gerade.md): Zeigt, wer gerade tippt.
- [Anpinnen](anpinnen.md): Wichtige Nachrichten griffbereit halten.
- [Suche](suche.md): Nachrichten finden, in allem, was man lesen darf.
- [Link-Vorschau](link-vorschau.md): Titel, Text und Bild unter Nachrichten mit Link.
- [Entwürfe und Tastenkürzel](entwuerfe-und-tastenkuerzel.md): Halbfertiger Text bleibt, Bedienung geht ohne Maus.

## Medien

- [Dateien und Bilder](dateien-und-bilder.md): Dateien im Chat teilen, Bilder groß ansehen.
- [GIFs](gifs.md): GIF-Suche über GIPHY direkt im Eingabefeld.
- [Sprachnachrichten](sprachnachrichten.md): Kurze Aufnahmen statt Text.
- [Sprachnachrichten abschreiben](sprachnachrichten-abschreiben.md): Text unter Sprachnachrichten, erzeugt auf dem eigenen Server.
- [Diktieren und Vorlesen](diktieren-und-vorlesen.md): Sprache zu Text und Text zu Sprache, im Browser.

## Server

- [Server und Einladungen](server-und-einladungen.md): Ein Server pro Gruppe, beitreten per Link.
- [Kanäle und Kategorien](kanaele-und-kategorien.md): Kanäle anlegen, ordnen, umbenennen und löschen.
- [Rollen und Rechte](rollen-und-rechte.md): Pro Server festlegen, wer was darf und wer welchen Kanal sieht.
- [Entfernen und Sperren](moderation.md): Mitglieder vom Server nehmen.
- [Begrüßung neuer Mitglieder](begruessung.md): Eine kleine animierte Zeile, wenn jemand beitritt.

## Privat

- [Freunde](freunde.md): Freundesliste mit Online-Anzeige.
- [Private Chats](private-chats.md): Nachrichten zu zweit, mit allem, was Kanäle können.
- [Gruppenchats](gruppen.md): Private Runden bis 10 Personen.

## Sprechen

- [Sprachkanäle](sprachkanaele.md): Offene Räume zum Reden.
- [Push-to-Talk und Rauschfilter](push-to-talk-und-rauschfilter.md): Mikrofon nur beim Halten offen, Rauschfilter abschaltbar.
- [Anrufe und Video](anrufe-und-video.md): Sprach- und Videoanrufe in privaten Chats und Gruppen, Kamera auch im Sprachkanal.
- [Bildschirm teilen](bildschirm-teilen.md): Bildschirm, Fenster oder Tab in Sprachkanal und Anruf zeigen.

## Du

- [Profil, Status und Abzeichen](profil-und-status.md): Wie du für andere erscheinst.
- [Server-Tags](server-tags.md): Kurzes Kürzel mit Emoji neben dem Namen.
- [Darstellung](darstellung.md): Farben, Dichte und Schriftgröße.
- [Mitteilungen](mitteilungen.md): Push auf Handy und Computer, auch bei geschlossener App.
- [App installieren](app-installation.md): disslxt läuft ohne App Store wie eine App.

- [Angemeldete Geräte](geraete.md): Sehen und beenden, wo man angemeldet ist.
- [Datenexport](datenexport.md): Eine Kopie der eigenen Daten als Datei.
- [Konto löschen](konto-loeschen.md): Das Konto und alles dazu selbst entfernen.
