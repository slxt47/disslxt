# Server-Tags

[Alle Funktionen](README.md)

Kurzes Kürzel mit Emoji neben dem Namen.

## Bedienung

- Besitzer: Server-Einstellungen. Mitglieder: im Profil wählen.

## Regeln und Grenzen

- 2 bis 4 Buchstaben oder Ziffern.
- Verschwindet, wenn der Server den Tag entfernt oder man geht.

## Technik

- `users.tag_guild_id`, Kopie von Text und Emoji am Nutzer
